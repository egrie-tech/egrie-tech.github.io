2. What Soundtrail provides

Soundtrail lets you save private location-based music pins, organize local playlists, import audio, export/import library records, and configure opt-in place, motion, and time automations. Optional integrations support provider searches, external playback, Jellyfin playback/downloads, encrypted sync with our default server or a self-hosted server you choose, and permission-confirmed YouTube audio extraction.

Features depend on your device, permissions, connectivity, provider authorization, and server configuration. Soundtrail does not supply ownership of music or a subscription to any provider. 3. Accounts, credentials, and recovery keys

The app is configured to connect to our server by default, and you may choose a self-hosted server instead. A Soundtrail account is required for server features such as sync and the authenticated audio extractor, not for local library features. If you use sync, use accurate account information and keep your password, server session, and encryption recovery key secure. Only connect accounts and servers you are authorized to access. Let the relevant operator know if you suspect unauthorized access.

The sync recovery key is needed to decrypt your library. The supplied server cannot reset or reconstruct it, and changing an account password does not recover encrypted data. There is no password-reset service in the reviewed server implementation. Keep a secure backup of your key and library; do not share credentials or the recovery key in public support requests.

If you run a server, you are responsible for its deployment, updates, HTTPS, access controls, storage, logs, backups, and any privacy or legal obligations to its users. Hosting Soundtrail code does not make the project maintainer the operator of your server.
